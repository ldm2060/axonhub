# Admin All Requests Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an owner-only admin request log page that shows all users' requests with user, API key, and project context while preserving the existing request table and detail behavior.

**Architecture:** Reuse the existing `frontend/src/features/requests` feature with an explicit admin scope. Admin scope disables selected-project scoping, requests ownership fields from GraphQL, enables global filter option loading, and routes details under `/admin/requests/$requestId`.

**Tech Stack:** React 19, TypeScript, TanStack Router, TanStack Query, TanStack Table, GraphQL over `/admin/graphql`, Zod schemas, Tailwind CSS.

---

## File structure

- Modify `frontend/src/features/requests/data/schema.ts`
  - Add optional `project` to the request schema so admin table rows can render project names.
- Modify `frontend/src/features/requests/data/requests.ts`
  - Add an `includeAdminFields` query option.
  - Include `project` and `apiKey.user` only when admin mode requests them.
  - Pass the same option through list, detail, polling, and adjacent-page queries.

  - Add global/admin options to `useApiKeys` so API key filter options can load without a selected project header.
- Modify `frontend/src/features/requests/index.tsx`
  - Add `scope="project" | "admin"` support.
  - Disable project scoping and route details to `/admin/requests/$requestId` in admin mode.
- Modify `frontend/src/features/requests/components/requests-table.tsx`
  - Pass admin-scope flags to columns, toolbar, and drawer.
- Modify `frontend/src/features/requests/components/data-table-toolbar.tsx`
  - Load channel and API key filter options globally in admin mode.

  - Use global request detail and adjacent-page queries in admin mode.

  - Add admin-only Project and User columns; keep the existing API Key column.
- Modify `frontend/src/features/requests/components/request-detail-global-page.tsx`
  - Make the component route-agnostic and allow admin back navigation.
- Create `frontend/src/routes/_authenticated/admin/requests/index.tsx`
  - Render the request list in admin mode.
