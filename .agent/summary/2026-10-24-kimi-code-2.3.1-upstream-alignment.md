# Kimi Code 反代对齐 MoonshotAI/kimi-code@2.3.1

**日期：** 2026-10-24
**状态：** 已完成（build/lint/test 全绿，本地服务已重启验证）

## Context

AxonHub 的 `kimi_code` OAuth 通道（Kimi Code 反代）此前对照官方 npm 包 0.27.0 的打包产物实现。官方仓库现已开源（MoonshotAI/kimi-code，CLI 2.3.1），OAuth、模型目录、推理请求编码、用量端点均有演进。本次按最新源码重新对齐。

## 官方源码关键事实（对照依据）

| 组件 | 官方 2.3.1 行为 | 来源 |
|------|----------------|------|
| CLI 身份 | `kimi-code-cli/2.3.1`，platform `kimi_code_cli` | `apps/kimi-code/package.json`、`src/cli/version.ts`、`src/constant/app.ts` |
| OAuth | host `auth.kimi.com`，client_id 不变，device flow 端点不变 | `packages/oauth/src/constants.ts`、`src/oauth.ts` |
| 区域 | 新增 global 区：`auth.kimi.ai` + `api.kimi.ai/coding/v1` | `packages/oauth/src/region.ts` |
| /models 响应 | `data[].{id, limit.context, display_name, supports_tool_use, modalities.input, reasoning.{type, effort.{valid,default}}, protocol}`；protocol ∈ {`anthropic`, `response`}，缺省为 Kimi chat completions | `packages/oauth/src/managed-kimi-code.ts` (toModelInfo/parseModelProtocol/parseModelReasoning) |
| Anthropic 协议请求 | `POST {base}/messages?beta=true`，body `betas`（不发明 anthropic-beta 头）；thinking 配置时 `thinking:{type:"enabled"|"disabled"}` + `output_config:{effort}`，betas=`[context-management-2025-06-27]`；未配置 thinking 时 betas=`[interleaved-thinking-2025-05-14]`；budget_tokens 不被发送 | `agent-core-v2/src/human/llm-kimi/trait.ts` (kimiAnthropicTrait)、`requester/bases/anthropic/{requester,format,profile}.ts` |
| chat completions 协议 | `thinking:{type:"enabled"|"disabled", effort}`（kimiOpenAITrait），`max_completion_tokens` 优先，流式 `stream_options.include_usage` | `trait.ts` (kimiOpenAITrait) |
| Responses 协议 | protocol=`response` 的模型 POST `{base}/responses` | kosong/agent-core-v2 openai_responses requester |
| /usages 响应 | `usages.{limit_5h, limit_7d, limit_month_total, limit_month_code}.{used_ratio, reset_time}` + `boosterWallet` | `packages/oauth/src/managed-usage.ts` |

TUI 主路径已切换到 agent-core-v2 引擎（kimi-tui.ts "v2 engine"），thinking 编码以 `kimiAnthropicTrait` 为准。

## 变更清单

1. `llm/transformer/kimicode/constants.go`：`CLIVersion` 0.27.0→2.3.1；新增 `GlobalOAuthHost/GlobalBaseURL`、`ProtocolResponse`、`ResponsesPath`、beta 常量。
2. `llm/oauth/credentials.go`：`KimiCodeModel` 新增可选 `display_name`（存量凭据不受影响）。
3. `llm/transformer/kimicode/models.go`：`FetchModels` 解析最新嵌套结构（limit.context/modalities/reasoning/protocol），旧扁平字段回退兼容；protocol `response` 合法化。
4. `llm/transformer/kimicode/outbound.go`：
   - Anthropic 路径：thinking 请求 → `{"type":"enabled"}`（剥离 budget_tokens/display），effort → `output_config.effort`，betas=`[context-management-2025-06-27]`；disabled → 同 beta；未配置 → betas=`[interleaved-thinking-2025-05-14]`；保留 `?beta=true` 与 Anthropic-Beta 删除。
   - 新增 Responses 路径：protocol `response` 模型经 `openai/responses` transformer POST `{base}/responses`。
   - Kimi 路径：`reasoning_effort` → `thinking:{type, effort}`（none→disabled、minimal→low、xhigh→max）。
5. `internal/server/biz/provider_quota/kimi_code_checker.go`：`/usages` 新格式（ratio 型）解析，旧格式回退；共用装配逻辑重构。
6. 测试：identity/httpclient 版本断言更新；outbound 新断言（enabled thinking、output_config、beta 值、responses 路由、kimi thinking 映射）；models 新旧格式解析测试；quota checker 新格式测试。

## 兼容性

- 存量 `kimi_code` 通道凭据（旧扁平模型元数据）无需重登即可继续使用。
- OAuth device flow / token 刷新 / 身份头协议未变，无需重新授权。
- `moonshot_coding` API-key 通道的 quota 展示在新旧两种 /usages 响应下均工作。
